# PeerConnection

不想用 `createHostSession` 时，可以自己管底层连接。

```ts
import { PeerConnection, Connection, startHost } from '@ofc-gm/framework'
import { server } from './server'
import { client } from './client'

const peer = new PeerConnection()
peer.setNetwork('lan')
peer.setRole('answer') // 或 'offer'
peer.createPeer()

// offer 端：先 generateSDP，再 accept 对方的 answer
// answer 端：先 accept 对方的 offer，再 generateSDP

peer.onChannelOpen = () => {
  const connection = new Connection(peer, 'text')
  connection.connect()
  startHost({ connection, server, client })
}
```

- **offer**：先 `generateSDP()`，再 `acceptRemoteSDP(answer)`
- **answer**：先 `acceptRemoteSDP(offer)`，再 `generateSDP()`

手动交换 UI 可用 `@ofc-gm/components` 的 `OfcSignalExchange`，把外部创建好的 `peer` 传进去即可。
