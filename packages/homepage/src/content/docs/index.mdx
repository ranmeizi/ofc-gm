# OFC-GM Docs

办公场景 WebRTC 小游戏框架的文档站（App Router + MDX + SSG）。

## 你在看什么

- **Docs**：写在 `content/docs/*.mdx`，构建时静态生成
- **Examples**：可交互的 React 示例页，UI 用 [retro-react](https://github.com/retro-react/retro-react)

1. 读 [Getting Started](/docs/getting-started)
