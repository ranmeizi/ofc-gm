# OFC-GM

用 WebRTC 在浏览器里开局域网 / 公网小游戏：一方建房当权威，其他人连上来一起玩。

你主要写两份逻辑：

1. **server** — 游戏规则与状态
2. **client** — 画面与输入

连接（复制粘贴信令或 WebSocket）做好之后，再交给框架开房。
