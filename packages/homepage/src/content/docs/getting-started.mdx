# Getting Started

## 仓库包

| 包 | 作用 |
| --- | --- |
| `@ofc-gm/framework` | WebRTC / PeerConnection / Connection |
| `@ofc-gm/components` | 信令交换 Web Component + React 包装 |
| `@ofc-gm/ws` | 两人房 WebSocket 信令中继 |
| `homepage` | 本文档站 + examples |

## 本地开发

```bash
pnpm install
pnpm dev:home      # 文档站
pnpm dev:ws        # 信令服务（WS 交换测试需要）
pnpm dev:testing   # 交互测试页
```

## 怎么写文档

在 `content/docs/` 新增 `.mdx`，并在 `src/lib/docs.ts` 的 `DOC_PAGES` 里登记 slug。

```mdx
# 标题

正文支持 **Markdown**，也可以嵌入 React 组件。
```
