# 安装

```bash
pnpm add @ofc-gm/framework
```

常用配套：

| 包 | 什么时候用 |
| --- | --- |
| `@ofc-gm/components` | 页面里嵌入手动交换信令的 UI |
| `@ofc-gm/ws` | 用 WebSocket 自动传 SDP（需自己部署或本地 `pnpm dev:ws`） |

## 最小流程

```ts
import { createHostSession, startHost } from '@ofc-gm/framework'
import { server } from './server'
import { client } from './client'

const session = createHostSession({ network: 'lan' })

// 用你的 UI 完成信令交换……
await session.acceptRemoteSignal(guestOffer)
const answer = await session.generateLocalSignal()
await session.whenReady()

startHost({ session, server, client })
```
